# Computational Linguistics & Natural Language Processing

##  Overview

This repository contains the LSTM Practice Questions assignment for Computational Linguistics and Natural Language Processing (CL & NLP). It covers numerical problems and theoretical concepts related to LSTM networks, sequential data processing, time-series forecasting, and classification evaluation.

##  Topics Covered

- **LSTM Architecture:** Understanding forget, input, and output gates, cell state, and hidden state.
- **LSTM Forward Pass:** Numerical calculations for updating cell and hidden states.
- **Trainable Parameters:** Calculating the number of parameters in an LSTM layer under different bias configurations.
- **Vanishing Gradient:** Analyzing gradient behavior and the role of forget gates in learning long-term dependencies.
- **Time-Series Forecasting:** Preparing hourly electricity load data using sliding windows, training samples, and mini-batches.
- **Min-Max Normalization:** Scaling vibration sensor readings for machine learning applications.
- **Predictive Maintenance:** Using predicted probabilities and decision thresholds to identify potential equipment failures.

##  Model Evaluation

The assignment explores binary classification using a confusion matrix and the following evaluation metrics:

- **Precision:** Measures the correctness of positive predictions.
- **Recall:** Measures how many actual positive cases are identified.
- **F1-Score:** Balances precision and recall.
- **Accuracy:** Measures the proportion of correct predictions.

It also examines why recall and F1-score are important when evaluating failure prediction models on imbalanced datasets.

##  Key Learning Outcomes

- Understand LSTM architecture and its internal operations.
- Calculate trainable parameters and analyze gradient behavior.
- Prepare sequential data for time-series forecasting.
- Apply normalization and binary classification concepts.
- Evaluate model performance using classification metrics.

## Concepts & Techniques

Computational Linguistics, NLP, RNN, LSTM, Deep Learning, Sequential Data Processing, Time-Series Forecasting, Min-Max Normalization, Predictive Maintenance, and Classification Evaluation.

##  Purpose

The objective of this assignment is to develop a practical and mathematical understanding of LSTM networks and their applications in sequential prediction, time-series forecasting, and equipment failure detection.
